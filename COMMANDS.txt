Recipe Framework Survival — Commands
====================================
Author: Zernon916

Host / single-player. Dev cheats default ON via rfs_settings.json
("cheats": true). Set "cheats": false for public Workshop builds.
Set "setupQuestTab": false to hide the /setup Quest tab.

Help
----
  /menu                Open player menu (Map + Growth Time overlay) — all players
  /help
  /commands
  /setup               Host-only world setup (Main / Farming / Quest / Inventory)
  /gensettings         Host-only gen settings (cheats, modded blocks, features,
                       Streamer mode for Discord vote drops — see below)
  /map                 Toggle top-down camera map (WASD pan, scroll zoom)
  /mapclose            Close the map camera
  /rfsmap              Alias of /map

Cheats default from rfs_settings.json; host /gensettings can override per world.
Set "frameworkOnly": true for baseline mode (cheats + quest UI off; hooks stay on).

                       Needs RFS Beacons Blocks & Parts enabled in world Mods.
                       Wire a Battery container. Optional switch.
                       Craftbot: Hack 1 Metal. Hideout: 20 / 50 / 120 Farmers.
                       E on powered beacon = Orders (Rest/Defend/Farm/Collect/Oil).

Quests
------
  /questlist
  /rfsquestlist        alias of /questlist
  /questinfo <name>
  /completequest <name>   completes, grants rewards (schematics/logs/items),
                          and activates next main-story quest when mapped
  /startquest <name>      QuestManager.Sv_TryActivateQuest
  /resetquest <name>      abandons if active; full reset N/A (no API)

Map (/map)
----------
  Toggle open/close with /map again.
  While open: WASD pan, scroll zoom, RMB or LMB recenter on you, E / Esc / Jump close.
  Character is locked (immovable) while the map is open. No craftable map tool.

Streamer / Discord
------------------
  In-game Streamer still works via file drops in %USER_DATA%/rfs_discord_bridge
  (RfsStreamer polls vote/chat JSON there). The Discord/streamer companion bot is
  NOT shipped inside the Steam/Workshop pack.

  Companion lives on GitHub only:
    https://github.com/zernon916/Recipe-Framework-Systems
    (discord-bridge/ folder in that repo)

  Host setup: clone the GitHub repo, configure discord-bridge/.env, then from
  discord-bridge run: npm install && npm run watch
  (watcher polls start/stop requests written by /gensettings Discord tab).

  Host /gensettings -> Streamer ON (+ Discord chat relay if wanted). Discord /vote
  writes a local JSON drop; RfsStreamer polls and spawn/gives.
