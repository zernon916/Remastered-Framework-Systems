[h1]Remastered Framework Survival[/h1]
[b]BETA[/b]

A Survival Custom Game for Scrap Mechanic. Hostile bots are corrupted - fight back with powered Hack Beacons, reclaim them as allies, then farm, craft, and rebuild.

Built as a full survival experience and as a framework other Blocks and Parts mods can plug into.

[hr][/hr]

[h2]Key Features[/h2]
[list]
[*][b]Menus[/b] - Player [b]/menu[/b] (map, growth overlay, options). Host [b]/gensettings[/b] (MAIN / FEATURES / STREAMERS / DISCORD). Host [b]/setup[/b] opens the Cheats tab. Type [b]/help[/b] in chat for the short command list.
[*][b]Hack Beacons[/b] - Place a Hack Beacon, wire a Rechargeable Battery Box, keep it powered. Hostile bots in range convert to tethered allies (raid-only). Cap starts at 4 bots. Hideout schematic unlocks the beacon. Cheat: [b]/givehack[/b].
[*][b]Radio Modules[/b] - Link Radio Brick (max 1), Antenna (max 2), and Lock (max 1) to the beacon for more range, higher bot cap, and longer convert hold. Keep the electricity connection to the beacon.
[*][b]Beacon Orders[/b] - Press [b]E[/b] on a powered beacon for Orders: Rest / Defend, Stay / Recall, Hay Farm, Tote Collect, Waterbot Collect Oil, rename, color, Master / Slave linking, and Show Range.
[*][b]/unhijack[/b] - Release your nearest owned ally (host can release any).
[*][b]Map[/b] - Always-on MiniMap (upper-left). Craft Nutt's GPS (Metal Block + Circuit Board + Component Kit + Glass), then use it to open the full atlas. Terrain / atlas by [b]Nutt[/b] ([url=https://steamcommunity.com/sharedfiles/filedetails/?id=3780282057]World Map 3780282057[/url]). Do [b]not[/b] enable World Map as a world mod (double HUD). Ammo stays on the HUD.
[*][b]Farming[/b] - Soil Bag places on flat ground (drag to lay a rectangle when Fast Place is on). Growth Time overlay. Host Farming tools in [b]/gensettings[/b] / cheats: Instant Farm, Always Watered, Dirt on Blocks, Fast Place, Fast Pickup.
[*][b]Chemical Regeneration Station[/b] - Step in to heal over time while the tank has charge. Solo night skip to 5 AM when it finishes filling.
[*][b]Beds[/b] - All beds (including Mattress) set your home and skip night to 5 AM when alone. Multiplayer vote-to-sleep is planned later.
[*][b]Solar Panels[/b] - Charge connected Rechargeable Battery Boxes.
[*][b]Inventory[/b] - Host can expand inventory size and toggle limited / unlimited for the whole session.
[*][b]Tile Loaders / Anchors[/b] - Keep distant areas loaded ([i]WARNING: loading many tiles hurts performance even on strong PCs[/i]).
[*][b]Streamer / Discord (optional)[/b] - In-game Streamer votes via file drops. Companion bot is on GitHub only (not in this Workshop pack).
[/list]

[hr][/hr]

[h2]For Modders[/h2]
[list]
[*][b]Store hooks[/b] - Inject Craftbot, Farmers Hideout, and Mining Hub rows via JSON (ModDatabase).
[*][b]Schematics[/b] - Unlockable Craftbot recipes sold at the Hideout (vanilla schematic path).
[*][b]RfsQuest API[/b] - Wrappers around Survival QuestManager (see MODDER_API.txt).
[*][b]frameworkOnly[/b] - Flag in rfs_settings.json to keep hooks on while turning off default cheat / quest tooling.
[/list]

[hr][/hr]

[h2]Install[/h2]
[olist]
[*]Subscribe to [b]ModDatabase[/b] (keep installed; do [b]not[/b] enable as a world mod).
[*]Create a new world with [b]Remastered Framework Survival[/b].
[*]Enable the Blocks and Parts mods you want (example: Intelligentia).
[*]If you already have [b]World Map[/b] by Nutt, do [b]not[/b] enable it as a world mod.
[/olist]
